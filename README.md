# Watson Recipes

A small, local-first recipe app for planning shared meals with vegetarian and protein-focused options.

## Run it

Open `index.html` in a browser. No build step or dependencies are required. Cooking history, ratings, saved recipes, and links you add are stored in that browser's local storage.

The app includes 12 starter ideas, the 30 dinners and 10 standalone lunches from the Confluence planner, and the 30 dinners from the Google Docs plan. Its two featured Google Docs recipes include full ingredients and methods. Planner entries link back to their source pages; starter ideas use a web search for recipe examples. Search covers titles, summaries, protein swaps, and available ingredient/method text, with title matches ranked first. Recipe photos are illustrative images loaded from Unsplash, not verified photos of each exact dish.
